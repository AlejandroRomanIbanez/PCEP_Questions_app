==QUESTION 1==
Which of the following statements about Python strings is true?
[A] They are mutable and can be changed in-place.
[B] They are immutable, and any method that "changes" a string returns a new string.
[C] They can only be created using single quotes.
[D] String methods like `.upper()` modify the string directly.

CORRECT: B
EXPLANATION: Strings in Python are immutable. This means that once a string is created, it cannot be changed. Methods like `.upper()`, `.replace()`, etc., do not alter the original string; they create and return a new, modified string.

==QUESTION 2==
What is the output of the following code?
`print("python".find('p'))`
[A] `True`
[B] `1`
[C] `-1`
[D] `0`

CORRECT: D
EXPLANATION: The `.find()` method returns the lowest index of the substring if found. Since 'p' is the first character, its index is 0.

[A] `'Heppo'`
[B] `'Heplo'`
[C] `'Heppoworld'`
[D] `'Hepllo'`

CORRECT: D
EXPLANATION: The `.replace()` method can take an optional third argument, `count`, which limits the number of replacements. In this case, only the first occurrence of 'l' is replaced with 'p'.

==QUESTION 8==

[A] `**exam**`
[B] `*exam*`
[C] `exam****`
[D] `****exam`

CORRECT: A
EXPLANATION: `.center(width, fillchar)` returns a new string of the specified `width`, centered, and padded with the `fillchar`. With a width of 8 for a 4-character string, 4 padding characters are needed, 2 on each side.

==QUESTION 9==

[B] It raises a `ValueError`.
[C] It splits the string by any sequence of whitespace and discards empty strings.
[D] It splits the string by single spaces only.

CORRECT: C
EXPLANATION: When called without a separator, `.split()` treats any consecutive whitespace as a single delimiter and removes any empty strings from the result, which is very useful for parsing text.

[B] `'ple'`
[C] `'l'`

==QUESTION 30==
What is the result of the comparison `'apple' > 'Apple'`?
[A] `True`
[B] `False`
[C] It raises a `TypeError`.
[D] It depends on the operating system.

CORRECT: A
EXPLANATION: String comparison is done lexicographically based on the Unicode code points of the characters. In ASCII/Unicode, lowercase letters have higher code points than uppercase letters (`ord('a')` is 97, `ord('A')` is 65), so `'apple'` is "greater than" `'Apple'`.
