==QUESTION 1==
What is the primary function of the `__all__` list in a module's `__init__.py` file?
[A] To prevent any modules from being imported.
[B] To list all private variables that should not be accessed.
[C] To define the public API of the package for wildcard imports (`from package import *`).
[D] To automatically import all the listed modules.

CORRECT: C
EXPLANATION: The `__all__` list specifies which names (modules, functions, variables) should be imported when a user performs `from package import *`. It acts as a public API definition.

==QUESTION 2==
If you run a script `main.py` containing `import my_module`, where will the Python interpreter look for `my_module.py` first?
[A] In the Python standard library installation directory.
[B] In the directory containing the `main.py` script.
[C] In the directories listed in the `PYTHONPATH` environment variable.
[D] In the `site-packages` directory.

CORRECT: B
EXPLANATION: The first place Python's import mechanism searches is the directory of the script that initiated the import. This is the first entry in the `sys.path` list.

==QUESTION 3==
Which statement correctly describes a relative import?
[A] It's an import that uses the full path from the project's root directory.
[B] It's an import statement that starts with a `.` or `..` to import from a module within the same package.
[C] It's an import that is slower than an absolute import.
[D] It's an import that can only be used in the `__main__` script.

CORRECT: B
EXPLANATION: Relative imports use dot notation to specify locations relative to the current module's location. A single dot (`.`) refers to the current package, and two dots (`..`) refer to the parent package.

==QUESTION 4==
What does the `platform.processor()` function typically return?
[A] The Python interpreter's version.
[B] The operating system name.
[C] The real processor name, e.g., 'i386' or 'x86_64'.
[D] The machine's network name.

CORRECT: C
EXPLANATION: `platform.processor()` returns a string identifying the processor architecture. The exact output can be system-dependent.

==QUESTION 5==
What is the output of `math.modf(3.14)`?
[A] `(0.14000000000000012, 3.0)`
[B] `(3.0, 0.14)`
[C] `0.14`
[D] `3.0`

CORRECT: A
EXPLANATION: The `math.modf()` function returns a tuple containing the fractional and integer parts of a number. The fractional part comes first. Due to floating-point inaccuracies, the fractional part may not be exactly 0.14.

==QUESTION 6==
You want to select three unique winners from a list of 20 participants. Which `random` module function is best suited for this?
[A] `random.choices(participants, k=3)`
[B] `random.shuffle(participants)`
[C] `random.sample(participants, 3)`
[D] `random.randint(0, 19)` called three times.

CORRECT: C
EXPLANATION: `random.sample(population, k)` is designed to choose `k` unique elements from a population without replacement, making it perfect for this scenario. `choices` allows for duplicates.

==QUESTION 7==
A directory named `tools` contains `__init__.py` and `converter.py`. If `converter.py` contains a function `to_celsius()`, which import statement is invalid in a script outside the `tools` directory?
[A] `import tools.converter`
[B] `from tools import converter`
[C] `from tools.converter import to_celsius`
[D] `from .converter import to_celsius`

CORRECT: D
EXPLANATION: The relative import syntax `from .converter...` is only valid for use inside the `tools` package itself. It cannot be used by an external script.

==QUESTION 8==

==QUESTION 9==
What is the result of `math.copysign(-5, 10)`?
[A] `-5.0`
[B] `5.0`
[C] `-10.0`
[D] `10.0`

CORRECT: B
EXPLANATION: `math.copysign(x, y)` returns a float with the magnitude of `x` but the sign of `y`. So, it takes the magnitude of -5 (which is 5) and the sign of 10 (which is positive), resulting in `5.0`.

==QUESTION 10==
How can you ensure that a sequence of numbers generated by the `random` module is the same every time your program runs?
[A] By calling `random.reproduce()` at the start.
[B] This is not possible as the numbers are truly random.
[C] By calling `random.seed()` with a specific integer value at the start.
[D] By saving the output to a file and reading it back.

CORRECT: C
EXPLANATION: The `random` module generates pseudo-random numbers. Providing a specific seed with `random.seed()` initializes the generator to a known state, making the subsequent sequence of generated numbers deterministic and reproducible.

==QUESTION 11==
A package `data` has a subpackage `science`. Inside `science`, a module `physics.py` exists. What is the correct absolute import for this module?
[A] `import science.physics`
[B] `import data.science.physics`
[C] `from data import physics`
[D] `import physics from data.science`

CORRECT: B
EXPLANATION: Absolute imports always specify the full path from the project's root directory (or a directory in `sys.path`). The complete path to the module is `data.science.physics`.

==QUESTION 14==
What happens if you try to import a module that does not exist?
[A] A `NameError` is raised.
[B] A `SyntaxError` is raised.
[C] A `ModuleNotFoundError` is raised.
[D] The program continues but the module name is `None`.

CORRECT: C
EXPLANATION: `ModuleNotFoundError` (a subclass of `ImportError`) is the specific exception raised when the Python interpreter cannot locate the requested module in any of the directories in `sys.path`.

==QUESTION 15==
If `random.randint(1, 10)` is called, what are the possible return values?
[A] Integers from 1 to 9.
[B] Floating-point numbers between 1.0 and 10.0.
[C] Integers from 1 to 10, inclusive.
[D] Integers from 2 to 10.

CORRECT: C
EXPLANATION: `random.randint(a, b)` returns a random integer `N` such that `a <= N <= b`. Both endpoints are included in the possible range.

==QUESTION 16==
What is the purpose of the `PYTHONPATH` environment variable?
[A] It specifies the path to the Python interpreter executable.
[B] It extends the default search path for modules (`sys.path`) with a list of directories.
[C] It sets the default encoding for Python source files.
[D] It defines the location of the standard library.

CORRECT: B
EXPLANATION: `PYTHONPATH` allows a user to add custom directories to `sys.path` so the interpreter can find modules that are not located in the script's directory or the standard `site-packages` location.

==QUESTION 18==
What is the value of a package's `__path__` attribute?

[B] A list containing the path to the package's directory, which is used for resolving subpackage imports.

==QUESTION 19==
How can you programmatically import a module using its name as a string?
[A] `import("my_module")`
[B] `__import__("my_module")` or `importlib.import_module("my_module")`
[C] `exec("import my_module")`
[D] This is not possible in Python.

CORRECT: B
EXPLANATION: The `importlib.import_module()` function is the modern and recommended way to perform programmatic imports. The built-in `__import__()` also works but is considered lower-level.

==QUESTION 20==
What is the difference between `random.randint(a, b)` and `random.randrange(a, b)`?
[A] `randint` includes the endpoint `b`, while `randrange` excludes it.
[B] `randrange` can take a `step` argument, while `randint` cannot.
[C] `randint` returns a float, while `randrange` returns an integer.
[D] Both A and B are correct.

CORRECT: D
EXPLANATION: `random.randint(a, b)` is equivalent to `random.randrange(a, b + 1)`. `randrange` uses a half-open range `[a, b)` like the built-in `range()` function and can also accept a `step` argument.

==QUESTION 24==
Consider this structure: `pkg/mod1.py` and `pkg/mod2.py`. Inside `mod1.py`, you want to import `func` from `mod2.py`. What is the correct relative import?
[A] `from ..mod2 import func`
[B] `from mod2 import func`

==QUESTION 25==
What happens if `__init__.py` is missing from a directory in modern Python (3.3+)?
[A] The directory can never be treated as a package.
[B] It can be treated as a "namespace package", which is a package without a physical file marker.
[C] It will raise an `ImportError` when you try to import it.
[D] It will work exactly like a regular package.

CORRECT: B
EXPLANATION: Since PEP 420, Python 3.3+ introduced implicit namespace packages. This allows directories without `__init__.py` files to be treated as packages, which is useful for splitting a single large package across multiple locations.

[C] It contains platform-independent bytecode, which is executed by the Python Virtual Machine (PVM).

==QUESTION 28==

[A] `8`
[B] `8.0`
[C] `9`
[D] `9.0`

CORRECT: B
EXPLANATION: The `math.pow()` function always returns a float, even if the result could be represented as an integer. This is different from the `**` operator, which would return an integer `8` in this case.

==QUESTION 29==
Which statement will successfully import a submodule `db` from a package `utils` and give it the alias `database`?
[A] `import utils.db as database`
[B] `import database from utils.db`
[C] `from utils import db as database`
[D] Both A and C are correct.

CORRECT: D
EXPLANATION: Both syntaxes achieve the same result. `import package.module as alias` imports the module and assigns it the alias. `from package import module as alias` imports the module into the current namespace under the given alias.
