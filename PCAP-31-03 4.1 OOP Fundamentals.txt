==QUESTION 1==
What is the role of the `self` parameter in a class method?
[A] It is a reference to the class itself.
[B] It is a reference to the specific instance of the class on which the method is called.
[C] It is optional and can be omitted.

==QUESTION 2==
What is the purpose of the `__init__` method in a Python class?
[A] To destroy an instance of the class.
[B] To be the first method executed when the module is loaded.
[C] To initialize the state of a new instance when it is created.
[D] To return a string representation of the object.

CORRECT: C
EXPLANATION: The `__init__` method is the constructor. It is automatically called when a new object is instantiated, and it is used to set up the initial attributes of that object.

==QUESTION 3==
What is the difference between a class variable and an instance variable?
[A] Class variables can only be accessed by class methods, while instance variables can be accessed by instance methods.
[B] Class variables are shared among all instances of a class, while instance variables are unique to each instance.
[C] Class variables are defined inside the `__init__` method, and instance variables are defined outside.
[D] There is no difference; the terms are interchangeable.

CORRECT: B
EXPLANATION: A class variable belongs to the class and is shared by all objects created from it. An instance variable is created for and belongs only to a specific instance.

==QUESTION 6==

==QUESTION 8==
What is the output of the following code?
```python
class Test:
    def __init__(self):
        self.x = 1
        self.__y = 2

t = Test()
print(t.x)
print(t.__y)
```
[A] It prints `1` and `2`.
[B] It prints `1` and then raises an `AttributeError`.
[C] It prints `1` and then raises a `NameError`.
[D] It prints `1` and then prints `None`.

CORRECT: B
EXPLANATION: `self.x` is a public attribute and can be accessed. `self.__y` is name-mangled to `_Test__y`, so accessing it directly as `t.__y` will result in an `AttributeError`.

==QUESTION 12==
If a class does not have an `__init__` method defined, what happens when you instantiate it?
[A] It raises a `TypeError`.
[B] The object is created, but it has no attributes.
[C] The `__init__` method from the parent `object` class is called, which does nothing.

==QUESTION 13==
How do you check if an object `obj` is an instance of a class `MyClass`?
[A] `type(obj) == MyClass`
[B] `isinstance(obj, MyClass)`
[C] `obj.__class__ is MyClass`
[D] All of the above are valid ways.

EXPLANATION: `isinstance()` is the recommended way because it also correctly handles inheritance (it returns `True` if `obj` is an instance of a subclass of `MyClass`). `type()` only checks for an exact match.

==QUESTION 15==
What is the output of the following code?
```python
class A:
    val = 1
class B(A):
    pass
class C(A):
    pass
print(A.val, B.val, C.val)
B.val = 2
print(A.val, B.val, C.val)
```
[A] 1 1 1 and then 1 2 1
[B] 1 1 1 and then 2 2 2
[C] 1 1 1 and then 1 2 2
[D] 1 1 1 and then 2 2 1

CORRECT: A
EXPLANATION: Initially, `B` and `C` inherit `val` from `A`. When `B.val = 2` is executed, it creates a new class attribute `val` specifically for class `B`. This does not affect the `val` attribute in `A` or the inherited `val` in `C`.
